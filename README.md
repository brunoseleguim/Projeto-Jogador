# Projeto Jogador

É um projeto com o intuito de fazer cadastro e login, para depois poder cadastrar e listar um jogador, para poder ter acesso a esses testes no backend, foi utilizado o Postman
## Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão 18 ou superior recomendada)
- [Git](https://git-scm.com/)

## Como baixar e rodar o projeto

Siga o passo a passo abaixo no terminal para executar a aplicação localmente:

### 1. Clone o repositório
git clone [https://github.com/brunoseleguim/Projeto-Jogador.git](https://github.com/brunoseleguim/Projeto-Jogador.git)
2. Acesse a pasta do projeto
Bash
cd Projeto-Jogador
3. Instale as dependências (node_modules)
Como a pasta node_modules não é versionada no Git, execute o comando abaixo para baixar todas as bibliotecas necessárias:

Bash
npm install
4. Inicie o servidor de desenvolvimento
Se o projeto foi criado com Vite:

Bash
npm run dev
Se o projeto foi criado com Create React App:

Bash
npm start
Após iniciar, abra o navegador no endereço exibido no terminal (geralmente http://localhost:5173 ou http://localhost:3000).

Scripts disponíveis
npm install — Instala as dependências listadas no package.json.

npm run dev / npm start — Inicia o projeto em modo de desenvolvimento.

npm run build — Gera a versão otimizada para produção.
